# Sales Data Analysis & Prediction

## Project Overview

This project analyzes sales data using Python and applies Machine Learning to predict sales for a new order.

## Objectives

- Analyze overall sales performance
- Identify the best-selling products
- Compare sales across categories
- Visualize sales trends and relationships
- Build a Linear Regression model for sales prediction

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Dataset

The dataset contains sales information such as:

- Order ID
- Product
- Category
- Quantity
- Price
- Sales

This project uses a small sample dataset for learning and demonstration purposes.

## Data Analysis

Performed:

- Data checking
- Missing value analysis
- Duplicate checking
- Statistical analysis
- Product-wise sales analysis
- Category-wise sales analysis
- Average sales analysis
- Business insights

## Data Visualization

Created visualizations for:

- Total Sales by Product
- Total Sales by Category
- Quantity vs Sales
- Average Sales by Product
- Actual vs Predicted Sales

## Machine Learning

A **Linear Regression** model was trained to predict sales using:

- Quantity
- Price

## Model Evaluation

The model was evaluated using:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- R² Score

Because the dataset is very small, the evaluation results should be considered for learning and demonstration purposes rather than real-world performance.

## Business Insights

- Total Sales: ₹598,000
- Total Quantity Sold: 33
- Best-Selling Product: Phone
- Phone Sales: ₹283,000
- Highest-Selling Category: Electronics
- Electronics Sales: ₹544,000

## Prediction

The trained model was also used to predict sales for a new order.

## Conclusion

This project demonstrates how Python, data analysis, visualization, and machine learning can be combined to understand sales data and make sales predictions.
